# ⚡ rts-docs // Fullstack Web Documentation for r.outers

> Autonomous AI Coding Agent for Android Termux & Linux Documentation & Interactive Terminal Web Simulator.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fmyramm%2Frts-docs)

---

## ✨ Features
- ⌨️ **Live Interactive Web Terminal Simulator** (2-line prompt with history cycling & slash commands)
- ⚡ **80+ Models Catalog Explorer** (NVIDIA NIM, Clouvia, OpenAI)
- 🧩 **Skill Ecosystem Catalog & SKILL.md Generator**
- 🔑 **Complete Manual JSON Setup Guide** (`~/.routers_config.json`)
- 🔍 **Instant Search (`⌘K` / `Ctrl+K`)**
- 🔌 **Serverless REST API Endpoints** (`/api/status`, `/api/models`, `/api/skills`)

---

## 🚀 Quickstart Local Run

```bash
# 1. Clone repository
git clone https://github.com/myramm/rts-docs.git && cd rts-docs

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
